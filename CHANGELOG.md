# Changelog — Koh-Vibe

Toutes les versions livrées. **Une version = une PR mergée sur `main`.**

Le numéro suit [semver](https://semver.org/lang/fr/) : `major` pour une rupture (format du spool,
contrat des hooks), `minor` pour une capacité nouvelle et visible, `patch` pour une correction,
une refonte interne ou de la doc.
